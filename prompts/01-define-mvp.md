# Определить MVP

Прочитай `AGENTS.md`. По проблеме ниже определи один local-first MVP, который студент может собрать в этом репозитории без сервера: **[вставьте проблему и целевого пользователя]**. Сформулируй пользователя, его основную задачу, один ключевой сценарий, минимальный набор сущностей и полей, критерии готовности и что сознательно не входит в MVP. Предложи, начать ли с Ideas или с Component Gallery, и назови существующие компоненты для повторного использования. Не добавляй авторизацию, API, облачную синхронизацию, новый UI-kit или зависимость. После согласования реализуй только этот срез с versioned localStorage, валидацией, доступным mobile-first UI и тестами изменённого поведения.
