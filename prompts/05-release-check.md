# Проверить релиз

Прочитай `AGENTS.md` и подготовь этот local-first MVP к публикации на GitHub Pages. Не меняй продуктовый scope, не добавляй сервер, секреты, API или зависимости. Выполни по порядку `npm run lint`, `npm run typecheck`, `npm run test`, `npm run test:e2e` и `npm run build`. Проверь, что маршруты, ссылки и тесты учитывают Pages-путь `/<repository>/`, а production-сборка содержит PWA-артефакты. Если проверка не проходит, исправь причину в рамках существующей архитектуры и повтори затронутые проверки. В конце дай краткий отчёт: выполненные команды, результаты, изменённые файлы, URL/действия для Pages и оставшиеся риски.
