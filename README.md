# MVP PWA Starter Kit

## Что это

Это local-first starter kit для быстрого создания учебного MVP: мобильное React-приложение хранит данные в браузере, работает без сервера и может быть опубликовано на GitHub Pages. Начните с примера Ideas или Component Gallery, затем превратите один понятный пользовательский сценарий в свой продукт.

## Быстрый старт

Нужен **Node.js 22** (проверьте: `node --version`) и npm. В корне созданного из шаблона репозитория выполните:

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения. Для остановки сервера нажмите `Ctrl+C`.

## Как работать с Hermes

Начните с функции **Ideas** или с **Component Gallery**: там есть готовые паттерны экранов, форм, списков, фильтров и состояний. Перед любой задачей попросите AI прочитать [`AGENTS.md`](AGENTS.md) — это обязательный контракт репозитория.

1. Опишите один пользовательский результат и выберите подходящий файл из [`prompts/`](prompts/).
2. Скопируйте запрос в Hermes и попросите сначала изучить существующие компоненты и пример Ideas.
3. Проверьте изменения локально, а затем попросите Hermes добавить или обновить необходимые unit- и браузерные тесты.
4. До публикации выполните все команды из раздела «Проверка перед публикацией».

Не просите Hermes добавлять сервер, авторизацию, API-ключи или облачное хранилище: это статический локальный MVP.

## Данные и приватность

Данные хранятся только в `localStorage` этого браузера и этого профиля браузера. Они не синхронизируются между устройствами и не отправляются на сервер по умолчанию. Экспортируйте JSON-файл как резервную копию; после очистки данных браузера восстановить записи нельзя, если JSON-экспорт не был сохранён.

## Публикация на GitHub Pages

1. Создайте собственный репозиторий кнопкой **Use this template**.
2. Закоммитьте изменения и отправьте их в ветку `main`: `git push origin main`.
3. В GitHub откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Дождитесь завершения workflow в разделе **Actions** и откройте ссылку, которую GitHub Pages покажет в настройках или в результате workflow.

Проект публикуется как сайт репозитория, поэтому приложение работает по пути вида `https://<пользователь>.github.io/<репозиторий>/`, а не только от корня домена.

## Проверка перед публикацией

Выполните команды по порядку:

```bash
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```
