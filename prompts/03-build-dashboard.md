# Построить дашборд

Прочитай `AGENTS.md`. Построй mobile-first дашборд для уже существующей локальной сущности **[название сущности]**. Покажи 3–4 полезные метрики, вычисленные только из записей в Zustand/localStorage, и один понятный график или распределение, используя существующие компоненты и Recharts. Добавь пустое состояние с действием, доступные подписи для графика и адаптацию без горизонтальной прокрутки. Не создавай сервер, API, новые пакеты или искусственные тестовые данные в production-коде. Добавь unit-тесты расчётов и браузерный сценарий, который создаёт локальные записи, перезагружает страницу и видит обновлённые показатели.
